Authenticate the feed

The token is an opaque handle. The backend maps it to the real API key and performs the Global Datafeeds Authenticate. The API key is never sent to this page.

Create a session key

A SHA-256 fingerprint of (apikey + username) is stored to detect duplicates. SHA-256 is one-way and cannot be reversed — so instead of sending the key to the browser, we hand back a random opaque token. Give that token to the operator for the Authentication tab. The real API key stays on the backend only.

Your tick & event logs

ticks-YYYY-MM-DD.jsonl — one JSON line per tick (time, exchange, symbol, ltp, pc, pcp, change, trade time).
events-YYYY-MM-DD.log — auth, instrument counts, subscribe, disconnects, errors.
Files are written on the server under the mounted /data/logs volume, so they survive container restarts.

Cached instrument files

One file per exchange per day, e.g. NFO-YYYY-MM-DD.json — the raw GetInstruments response. Plus _merged-*.json (per-exchange identifier lists) and _subscribed-*.json (the exact flat list actually subscribed). Symbols taken = the Identifier of every returned row, after optional INCLUDE_INSTRUMENT_TYPES / INCLUDE_PRODUCTS filters.
